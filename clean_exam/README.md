# 깔끔 시험지

학생이 푼 수학 시험지 사진에서 **필기만 지우고 인쇄된 문제 글자와 그림은 원래 양식 그대로**
남기는 도구입니다. 학원 내부에서만 씁니다.

현재 **2단계(웹사이트 + 강사별 키 설정 + 클로드 자동 검수)** 까지 되어 있습니다.
2-B(여러 장 PDF 묶음 정리), 3단계(학습 데이터) 이후는 아직 없습니다.

---

## 설치 → 실행

```bash
pip install -r requirements.txt
python run.py
```

브라우저에서 **http://localhost:8000** 을 엽니다. 처음 들어가면 강사 이름을 고르는 안내가 뜹니다.

### 다른 컴퓨터(같은 와이파이)에서 접속하는 법

1. 서버를 켠 컴퓨터의 IP 를 확인합니다. 윈도우는 `ipconfig` 의 "IPv4 주소", 맥은 `ipconfig getifaddr en0`,
   리눅스는 `hostname -I`. (예: 192.168.0.12)
2. 다른 컴퓨터·태블릿·휴대폰에서 **http://그IP:8000** (예: http://192.168.0.12:8000) 을 엽니다.
3. 안 열리면 서버 컴퓨터의 방화벽에서 8000 포트를 허용합니다
   (윈도우: "고급 보안이 포함된 Windows 방화벽" → 인바운드 규칙 → 포트 8000 TCP 허용).
   포트를 바꾸려면 `config.yaml` 의 `server.port` 를 고칩니다.

외부 인터넷에는 열지 않는다는 전제입니다(로그인 없음).

### 명령줄로 한 장만 처리하기 (웹 없이)

```bash
python -m engine.clean 사진.jpg --out 결과.png [--api-key sk-ant-...] [--quality] [--debug]
```

## 강사용: 키 넣는 법

키가 없어도 **그냥 됩니다.** 규칙만으로 필기를 지우고, 화면에
"Anthropic 키를 넣으면 더 정확하게 지울 수 있어요" 라고 알려 줍니다.
키를 넣으면 (1) 규칙이 애매해한 획을 클로드가 판정해 정확도가 오르고 (2) 결과를 클로드가 검수해
남은 필기·손상된 인쇄를 박스로 짚어 줍니다. 비용은 **키 주인의 Anthropic 계정**에 청구됩니다.

1. https://console.anthropic.com 로그인 → **API Keys** → **Create Key** → `sk-ant-…` 복사
   (다시 볼 수 없으니 바로 붙여넣기).
2. **Billing** 에서 결제 수단 등록 + 선불 크레딧 충전(소액이면 충분). 지출 한도(spend limit)를 걸어 두면 안심.
3. 화면 오른쪽 위 **⚙ 설정** → 키 붙여넣기 → **키 확인**. "키가 유효해요" 가 나오면 끝.
4. 모델은 **가성비(Haiku 계열, 기본)** / **고품질(Opus 계열, 비용↑)** 중 고릅니다.
5. 오른쪽 위 배지에서 **오늘 API 사용: N회 / 약 ₩X** 를 볼 수 있습니다(단가는 `config.yaml` 의 `claude.pricing`).

키는 **이 브라우저의 localStorage 에만** 저장됩니다. 다른 컴퓨터에서는 다시 넣어야 하고,
**키 지우기** 를 누르면 그 브라우저에서 사라집니다. 키가 틀렸거나 크레딧이 없으면
서버는 규칙만으로 처리한 결과를 주면서 화면에 원인을 한국어로 알려 줍니다(오류로 멈추지 않음).

### 화면 사용법 요약

- **사진 올리기**: 끌어다 놓기 / 클릭 / 📷 카메라. 여러 장 한꺼번에 가능(JPG·PNG·HEIC).
- **비교 보기**: 가운데 슬라이더를 좌우로 끌면 원본↔결과가 갈라져 보입니다.
- **조절**: 필기 제거 강도 · 색 필기 제거 민감도 · 그래프 굵기 · 글자 진하기. 움직이면 1초 안에
  미리보기(축소본)가 바뀌고, **원래 크기로 적용** 을 누르면 결과 파일이 갱신됩니다. API 는 다시 부르지 않습니다.
- **🔍 클로드 검수**: 결과에서 남은 필기·손상된 인쇄·끊긴 도형을 박스로 표시. 박스를 눌러
  "이건 필기니까 지워 / 이건 문제니까 살려" 를 고르면 그 부분만 다시 처리되고, 결정은
  `data/labels/corrections/` 에 학습 데이터로 기록됩니다.
- **모서리 수동 조정**: 자동 보정이 틀렸을 때 네 귀퉁이를 직접 끌어 맞춥니다.
- **PNG / PDF 내려받기**, **최근 작업**(다른 강사 작업 보기 토글).
- 흐리거나 어두운 사진은 **⚠ 다시 찍기 권장** 표시가 붙습니다(결과는 그래도 나옵니다).

## 키는 어디를 지나가고 어디에 남지 않나

이 프로젝트는 **서버에 운영자 키를 두지 않습니다(BYOK).** 강사가 각자 자기 키를 넣고
비용도 각자 부담합니다.

- 키가 지나가는 곳: 브라우저 localStorage → 요청 헤더 `X-Anthropic-Key` → `app/auth_key.py`(요청 처리 중 메모리)
  → 처리 프로세스(인자) → `engine.clean.clean_image(api_key=...)` → `engine/claude_judge.py` / `app/review.py`
  → `services/claude_client.py` → Anthropic 서버. **전부 함수 인자**이고, 전역 변수·설정 파일·`.env` 에 담기지 않습니다.
- 키가 **절대 남지 않는 곳**: 디스크(작업 기록 `data/teachers/*/jobs/`, 교정 기록 포함), 서버 로그,
  응답 캐시(`data/api_cache/`), 사용량 기록(`data/usage/`), 오류 메시지, 예외 스택.
  `sk-ant-` 로 시작하는 문자열은 로그 필터가 자동으로 `sk-ant-***` 로 가립니다
  (`services/key_safety.py`, 테스트 `tests/test_key_safety.py`, `tests/test_app.py` 가 가짜 키로 모든 라우트를
  두드린 뒤 로그·데이터 폴더를 grep 해 확인).
- 응답 캐시의 열쇠는 **이미지 해시 + 프롬프트 해시 + 모델명**뿐입니다. 키는 안 들어갑니다.
  그래서 같은 사진을 다른 강사가 올리면 두 번째 사람은 호출 0회로 재사용합니다.

## 조정하기

모든 값은 `config.yaml` 한 파일에 있고, 항목마다 "이 값을 올리면 어떻게 되는지"가 주석으로
붙어 있습니다. 자주 만지게 되는 것:

| 값 | 언제 만지나 |
|---|---|
| `stroke_filter.remove_threshold` / `keep_threshold` | 필기가 덜 지워지거나 인쇄가 지워질 때. 두 값 사이가 "애매" 구간이고, **이 구간만 판정관에게 가므로 넓히면 정확도↑·비용↑** |
| `color_filter.saturation_threshold` | 색펜이 덜 지워지거나(내린다), 컬러 인쇄가 지워질 때(올린다) |
| `graph_enhance.dilate_px` | 그래프를 더 굵게/얇게 |
| `finalize.bleed_through_cutoff` | 뒷장 비침이 남을 때(내린다), 흐린 인쇄가 날아갈 때(올린다) |
| `claude.max_judge_calls_per_page` | 한 장당 비용 상한 |

## 테스트

```bash
pytest -q          # 전부 mock. 키 없이 돌아간다
pytest -q --live   # 실제 API 를 한 번 부른다 (ANTHROPIC_API_KEY 필요, 소액 과금)
```

보정 정확도·필기 제거율·처리 시간을 자동으로 잽니다.

## 폴더

```
run.py      서버 실행 (uvicorn, 0.0.0.0:8000)
app/        FastAPI 라우트·강사/키 헤더 해석·작업 저장·처리 프로세스 풀·단일 HTML 화면(app/static)
engine/     이미지 처리 (웹과 독립, CLI 로도 실행 가능)
services/   Claude 호출 단일 창구 + 프롬프트 텍스트(코드에 하드코딩 안 함)
tests/      샘플 사진 + 합성 시험지 생성기 + 테스트
config.yaml 모든 조정 값
data/       올린 사진·결과·라벨·캐시·사용량 (깃에 올리지 않음)
```
