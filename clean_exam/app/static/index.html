Anthropic 키 만드는 법
  1. console.anthropic.com 에 로그인 → API Keys → Create Key → 만들어진 sk-ant-… 를 복사 (다시 볼 수 없으니 바로 붙여넣기)
  2. Billing 에서 결제 수단 등록 + 선불 크레딧 충전(소액이면 충분). 지출 한도(spend limit)를 걸어 두면 안심
  3. 여기에 붙여넣고 키 확인
  4. 비용 감각: 시험지 한 장 정리에 판정관 몇 호출(가성비 모델 기준 몇십 원 안팎). 화면 오른쪽 위에서 오늘 쓴 금액을 볼 수 있어요
